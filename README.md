## Профессиональная спецификация

* **Основная специализация**
  Проектирование и разработка интерактивных игровых приложений (Gamedev), а также создание скриптов и специализированных инструментов для автоматизации рутинных процессов.

* **Уровень квалификации и опыт**
  Уверенное владение языком JavaScript на уровне Middle. Опыт практической реализации комплексной игровой логики на базе фреймворка rod.js. Текущий вектор развития направлен на глубокое изучение архитектуры и оптимизации памяти в языке Lua.

* **Инженерный подход**
  Активная поддержка культуры и методологии Open Source через публикацию открытого и доступного для совместной работы кода. Предпочтение отдается модульной архитектуре с понятной структурой связей.

* **Методология отладки**
  Поиск и устранение дефектов программного обеспечения производятся путем локализации проблемных участков кода, пошагового интерактивного дебага и анализа вызовов непосредственно в среде разработки Visual Studio Code.
